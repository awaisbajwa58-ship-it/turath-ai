# تراث اے آئی (Turath AI)
### کلاسیکی اسلامی کتب و فتاویٰ کے ذخیرے سے سمارٹ فقہی و علمی معاون
**تیارکردہ:** مفتی محمد اویس باجوہ (Mufti Muhammad Awais Bajwa)

---

## 📖 تعارف (Introduction)
**تراث اے آئی (Turath AI)** ایک جدید، تیز رفتار اور فل اسٹیک ریسرچ پلیٹ فارم ہے جو ہزاروں کلاسیکی اسلامی کتب (الشاملة و تراث) کے ذخیرے سے نصوص، فتاویٰ اور احادیث کی تحقیق، تخریج اور تقابلی مطالعہ چند سیکنڈوں میں فراہم کرتا ہے۔

### 🌟 نمایاں خصوصیات (Key Features)
1. **جامع فقہی تحقیق:** سوال درج کرنے پر فقہی مذاہب (حنفی، مالکی، شافعی، حنبلی) کے دلائل اور تقابلی جائزے کا خلاصہ۔
2. **مستند مآخذ و حوالہ جات:** کتاب کا اصل نام، مصنف، جلد نمبر، صفحہ نمبر اور اصل عربی عبارت۔
3. **علمی و فقہی ترجمہ نگار (Technical Fiqh Translator):** کلاسیکی عربی عبارات کا لفظی، بامحاورہ اور دقیق فقہی اصطلاحی اردو ترجمہ۔
4. **بک ریڈر (Book Reader):** تراث کی کسی بھی کتاب کے مخصوص صفحے کو اصل متن میں براؤز کرنے کی سہولت۔
5. **زیرو لیٹنسی تیز رفتار سرچ:** لوکل ان میموری سیمیٹک ویکٹرز اور متوازی تلاش کی بدولت نتائج سیکنڈوں میں حاصل ہوتے ہیں۔

## 🚀 گٹ ہب (GitHub) پر اپلوڈ کرنے کا طریقہ

اس فولڈر کو اپنے GitHub اکاؤنٹ میں نئی ریپوزٹری کے طور پر اپلوڈ کرنے کے لیے اپنے ٹرمینل میں درج ذیل کمانڈز چلائیں:

```bash
# 1. اس فولڈر میں آئیں
cd turath-ai

# 2. گٹ شروع کریں
git init

# 3. تمام فائلیں شامل کریں
git add .

# 4. پہلی کمٹ کریں
git commit -m "Initial commit of Turath AI by Mufti Muhammad Awais Bajwa"

# 5. برانچ کا نام main رکھیں
git branch -M main

# 6. اپنی گٹ ہب ریپوزٹری کا لنک جوڑیں (اپنا یوزر نیم اور ریپو کا نام تبدیل کریں)
git remote add origin https://github.com/YOUR_USERNAME/turath-ai.git

# 7. گٹ ہب پر پش کر دیں
git push -u origin main
```

## 🌐 ورسل (Vercel) پر لائیو ایپ بنانے کا طریقہ

جب آپ پروجیکٹ GitHub پر پش کر لیں، تو Vercel پر اسے 1 منٹ میں لائیو کیا جا سکتا ہے:

1. [Vercel.com](https://vercel.com) پر جائیں اور اپنے GitHub اکاؤنٹ سے لاگ ان کریں۔
2. **"Add New..."** -> **"Project"** پر کلک کریں۔
3. اپنی **`turath-ai`** ریپوزٹری کو منتخب کر کے **"Import"** پر کلک کریں۔
4. **Environment Variables** کے سیکشن میں درج ذیل متغیر (Variable) شامل کریں:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** `آپ کی_گوگل_جیمنائی_کی` (Google AI Studio سے حاصل شدہ)
5. **"Deploy"** کے بٹن پر کلک کریں۔
6. ورسل چند سیکنڈ میں آپ کی ویب ایپلیکیشن کو لائیو کر کے ایک مفت لائیو یو آر ایل (جیسے `https://turath-ai.vercel.app`) فراہم کر دے گا۔

## 💻 مقامی کمپیوٹر (Locally) پر چلانے کا طریقہ

اگر آپ اسے اپنے کمپیوٹر پر چلانا چاہتے ہیں:

```bash
# 1. انحصار اور پیکجز انسٹال کریں
npm install

# 2. .env فائل بنائیں اور اپنی Gemini API Key درج کریں
cp .env.example .env

# 3. ڈیولپمنٹ سرور چلائیں
npm run dev
```

سرور چلنے کے بعد اپنے براؤزر میں **`http://localhost:3000`** کھولیں۔
